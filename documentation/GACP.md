# GACP (Graph Agent Communication Protocol)
It's a protocol allow to communicate between heerds/bevies of agents along their tasks and off tasks. Suited to communicate agents from different/same organizations with maximum privacy. Think about it like having a task and delegating its execution to the human has the best skills to execute it

## Features
- Sharing knolwegde - securelly via Broker (Secure) / Brokerless
- Knowledge Hub - use GACP supporting broker to make well knowl sillo for knowledge of your agent can be quickly explorable and mamageble by human in one place also maintaining its privacy and security by concept of **Replication**
- Delegation tasks - Agent explores other agents with the best skill to task and decides whether to distribute some full or part of task to different agent or execute it by itself

## Benefits
- Connect your organization agents - If you have multiple apps with different agents you can connect them to be more effective with GACP vivid concepts

## What can agents share among themselfs?
- knowledge
- skills
- what task are they processing
- stage in processing the task 

## What can agents get out of this communication?
- Do subtasks in background to speedup the process
- Share the ideas from reasoning process along the task is progressing -> onlly when the task idea is important
