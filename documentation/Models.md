# Models

RavenADK provides model contracts grouped by capability. Each group has its own public entry point,
provider adapters, capability metadata, and custom-model guidance.

## Model groups

- [Text-to-text models](models/text-to-text.md): generate text, reasoning, structured output, and streams.
- [Speech-to-text models](models/speech-to-text.md): transcribe audio from files, blobs, or buffers.
- [Text-to-speech models](models/text-to-speech.md): synthesize audio, with voice and alignment capabilities where supported.
- [Embedding models](models/embeddings.md): create vectors for semantic search and RAG.
- [Video models](models/video.md): generate provider-native video, unified audio-driven avatars, native two-stage video, and cascaded lip-sync refinement.

See the linked page for the detailed contract, provider list, capabilities, examples, and integration
notes for each model group.
