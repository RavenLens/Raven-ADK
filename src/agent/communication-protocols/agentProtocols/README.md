# Agent Protocols
Agent protocols is way to define how agent can communicate with external agents. <br>
Each agent protocol has to follow a [agentProtocolSchema.ts](./agentProtocolSchema.ts) that makes the definition for RavenADK agentic patterns what makes each protocol universally usefull for each agent

> Modify Schema along Schema implementation for desired agent/s or all agents from RavenADK to extend its current capabilities
